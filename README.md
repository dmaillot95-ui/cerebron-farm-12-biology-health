# CEREBRON Farm 12 — Biology Health

Mission: provide reusable evidence-disciplined reasoning across biology, health science, epidemiology, bioinformatics and biomedical evidence review.

Core rules:
- REALITY > COHERENCE
- CLAIM <= EVIDENCE
- OBSERVATION != CAUSATION
- ASSOCIATION != CLINICAL BENEFIT
- IN VITRO != IN VIVO
- ANIMAL MODEL != HUMAN EVIDENCE
- SIMULATION != EXPERIMENT
- PREPRINT != ESTABLISHED RESULT
- SAFETY BEFORE ACTION
- UNKNOWN REMAINS UNKNOWN
